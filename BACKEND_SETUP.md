# Panduan Backend Ucapan & Doa Restu (Wedding Wishes)

Web undangan **Rizky & Anggun** telah dilengkapi dengan sistem backend ucapan otomatis yang mendukung:
1. **Supabase (PostgreSQL - Paling Mudah & Direkomendasikan untuk GitHub Pages & Cloudflare Pages)**
2. **Cloudflare Pages Functions + D1 (SQLite)**
3. **LocalStorage Fallback (Langsung jalan otomatis saat ini tanpa konfigurasi apa pun)**

---

## Opsi 1: Menggunakan Supabase (Paling Mudah, Gratis & Instan)
Supabase menyediakan database cloud gratis dengan REST API instan tanpa perlu coding backend server. Cocok 100% untuk **GitHub Pages** dan **Cloudflare Pages**.

### Langkah-langkah (Hanya 2 Menit):
1. Buka [https://supabase.com](https://supabase.com) dan daftar/masuk akun gratis.
2. Klik **New Project**, beri nama (misal: `wedding-rizky-anggun`), dan tentukan password database.
3. Setelah project siap, buka menu **SQL Editor** di sidebar kiri, klik **New Query**, lalu salin & tempel kode SQL berikut:

```sql
-- 1. Buat tabel wedding_wishes
CREATE TABLE wedding_wishes (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL,
    comment TEXT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);

-- 2. Aktifkan Row Level Security (RLS)
ALTER TABLE wedding_wishes ENABLE ROW LEVEL SECURITY;

-- 3. Izinkan semua tamu membaca ucapan
CREATE POLICY "Public read wishes" 
ON wedding_wishes FOR SELECT 
USING (true);

-- 4. Izinkan tamu mengirim ucapan baru
CREATE POLICY "Public insert wishes" 
ON wedding_wishes FOR INSERT 
WITH CHECK (true);
```
4. Klik tombol **Run** (selesai membuat database!).
5. Buka menu **Project Settings** (ikon gear di kiri bawah) > **API**.
6. Salin dua nilai:
   * **Project URL** (misal: `https://abcdefghijkl.supabase.co`)
   * **Project API keys** bagian **`anon` `public`** (string panjang diawali `eyJ...`)
7. Buka file [assets/js/wedding-wishes.js](file:///Volumes/Data/Karya/WeddingRIzkyAnggun/assets/js/wedding-wishes.js), isi kedua nilai tersebut pada bagian atas:
```javascript
window.WEDDING_BACKEND_CONFIG = {
    supabaseUrl: "https://abcdefghijkl.supabase.co", // Salin URL Anda di sini
    supabaseAnonKey: "eyJhbGciOi...",              // Salin Anon Key Anda di sini
    tableName: "wedding_wishes",
    cloudflareApiUrl: "/api/wishes"
};
```
8. Commit & Push ke GitHub Pages / Cloudflare Pages. Semua ucapan tamu kini tersimpan live di cloud secara realtime!

## Opsi 2: Menggunakan Cloudflare Pages + D1 (SQLite)
Jika Anda mendeploy menggunakan **Cloudflare Pages** dan ingin menggunakan database **SQLite bawaan Cloudflare (D1)**:

File endpoint API sudah disiapkan di [functions/api/wishes.js](file:///Volumes/Data/Karya/WeddingRIzkyAnggun/functions/api/wishes.js).

### Langkah-langkah:
1. Di Cloudflare Dashboard, buka **Workers & Pages** > **D1 SQL Database** > **Create Database** (beri nama misalnya `wedding-db`).
2. Masuk ke console D1, jalankan SQL:
```sql
CREATE TABLE IF NOT EXISTS wedding_wishes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    comment TEXT NOT NULL,
    created_at TEXT NOT NULL
);
```
3. Di Cloudflare Pages Project Anda, buka **Settings** > **Functions** > **D1 Database Bindings**.
4. Tambahkan binding:
   * **Variable name:** `DB`
   * **D1 database:** pilih database `wedding-db` yang dibuat tadi.
5. Deploy Pages Anda. Web undangan akan otomatis mendeteksi endpoint SQLite `/api/wishes`!

## Opsi 3: Local Storage (Sudah Aktif Sekarang)
Jika Anda belum membuat Supabase atau Cloudflare D1, web undangan **sudah langsung berjalan dengan aman menggunakan LocalStorage fallback**:
* Dilengkapi dengan data contoh ucapan hangat dari teman & keluarga.
* Tamu baru tetap bisa mengirim ucapan dan melihat ucapannya langsung muncul di layar.
